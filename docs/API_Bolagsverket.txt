API för att hämta företagsinformation

Vårt API för företagsinformation är till för dig som vill hämta information om företag och företagande direkt in i dina egna system. Informationen kan du använda i din egen verksamhet eller när du utvecklar tjänster för dina kunder eller andra slutanvändare. Genom att köpa ditt data från oss får du en pålitlig partner som bidrar till trygghet och kvalitet i dina processer och hjälper dig att bygga smart, skalbart och kostnadseffektivt.

Som en del av avtalet för att hämta företagsinformation får du även tillgång till API:et för värdefulla datamängder. Operationer som ingår i API:et för värdefulla datamängder genomförs utan kostnad. På sidan API för värdefulla datamängder kan du läsa mer om vilken information som räknas som värdefull.

Anmäl dig som kund

Som kund får du tillgång till kontinuerligt uppdaterad data som kan bidra i din verksamhet som ett affärskritiskt stöd för beslut och ge förutsättningar att kunna automatisera tidskrävande manuella uppgifter.
Kostnaden för att använda vår tjänst

Kostnaden för vår tjänst är en anslutningsavgift som du betalar endast en gång. Efter det betalar du en månadsavgift för de antal transaktioner* du vill kunna göra per månad.

Operationer som ingår i API:et för värdefulla datamängder är gratis och räknas inte till de transaktioner som månadsavgiften omfattar.

* Med transaktion menar vi de frågor du ställer mot API:ets operationer genom att skicka in ett organisationsnummer och/eller personnummer.

Gör så här för att få tillgång till API:et

    Läs igenom villkoren i våra avtal.
    Begär tillgång
        Fyll i och skicka in kundanmälan.
    Avtala med oss
        Vi skickar ett avtal till dig.
        Du fyller i den nivå av transaktioner som ni önskar teckna avtalet för. Skriv under och skicka tillbaka avtalet till oss med post.
    Få API-nycklar (client_id och client_secret) till testmiljön
        När vi har mottagit avtalet får du så kallade API-nycklar till testmiljön skickade till dig via mejl och sms enligt de kontaktuppgifter du lämnade i formuläret.
    Koppla upp och testa
        I testmiljön kan du säkerställa att du kan koppla upp dina applikationer mot vårt API och att det fungerar som du har tänkt dig. Under tiden som du bara har tillgång till testmiljön faktureras inte månadsavgiften.
    Få API-nycklar (client id och client secret) till produktionsmiljön
        Hör du av dig till oss när du är klar med dina tester och vill få tillgång till produktionsmiljön.
        Du får nya API-nycklar (client_id och client_secret) att använda i produktionsmiljön.
    Kostnad och faktura
        När du har tillgång till produktionsmiljön kommer vi att börja fakturera den avtalade månadsavgiften och sedan är det bara för dig att börja använda tjänsten och tillgodogöra dig vår information om företag och företagande.
        Om du inte hört av dig till oss inom 3 månader kommer vi automatiskt att ge dig tillgång till produktionsmiljön.
    Använd vårt data!
        Nu kan du använda vårt API i dina system och i din verksamhet!

Information om vem som har rätt att skriva under i företagets namn

Genom att skicka in ett personnummer och ett organisationsnummer kan du få veta på vilka sätt personen har rätt att skriva under i företagets namn med rättslig verkan (firmateckning).

Informationen om vem eller vilka som är firmatecknare är viktig exempelvis när avtal ska tecknas, andra handlingar i företaget ska signeras eller när företaget ska företrädas hos domstolar eller myndigheter.

Du får veta om personen ifråga har rätt att teckna firman och på vilket sätt, exempelvis:

    ensam
    tillsammans med andra (deras personnummer)
    inte alls.

Teknik

Vårt API är en REST-tjänst baserad på http och json. Anrop mot tjänsten ska krypteras via https. Auktorisation av API-anrop görs med hjälp av OAuth 2.

Prestandan för detta API tillåter varje användare att göra 20 anrop/sekund.

Mer detaljerad beskrivning Länk till annan webbplats. av vårt API hittar du i vår utvecklarportal som finns i verktyget WSO2.

Testmiljö

I vår testmiljö kan du testa din integration mot vårt API när du har tecknat avtal med oss. Testmiljön innehåller ett antal testföretag och testpersoner och där kan du verifiera svaren du får från API:ets operationer. Observera att testmiljön inte innehåller alla möjliga kombinationer av alla informationsmängder och organisationsformer. Du hittar mer information om testmiljön och vårt testdata under Dokumentation i vår utvecklarportal Länk till annan webbplats..
Avtal

För att du ska kunna använda vårt API behöver du skriva ett avtal med oss där vi säkerställer att våra användarvillkor uppfylls.
