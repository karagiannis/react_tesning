\section*{1. Avtalets omfattning}

Detta uppdragsavtal reglerar de tjänster som Redovisningsbyrån AB ("Byrån") ska utföra åt Klienten. Avtalet träder i kraft vid signering och gäller tillsvidare med en uppsägningstid om tre (3) månader.

\section*{2. Tjänster som ingår}

Byrån åtar sig att tillhandahålla följande tjänster:

\subsection*{2.1 Löpande bokföring}
\begin{itemize}
  \item Kontroll och bokföring av verifikationer
  \item Kontering av inkommande och utgående fakturor
  \item Avstämning av bankkonton och kortavräkningar
  \item Momsredovisning och momsrapportering
  \item Arbetsgivardeklarationer (AGI) om klienten har anställda
\end{itemize}

\subsection*{2.2 Årsredovisning och deklaration}
\begin{itemize}
  \item Upprättande av årsbokslut och årsredovisning
  \item Deklaration till Skatteverket (inkomstdeklaration)
  \item Rådgivning inför bokslutet
\end{itemize}

\subsection*{2.3 Fakturering och betalningar}
\begin{itemize}
  \item Support för fakturering via Fortnox (om klienten väljer detta)
  \item Hantering av leverantörsfakturor
  \item Betalningsplanering och kassaflödesuppföljning
\end{itemize}

\subsection*{2.4 Ekonomisk rådgivning}
\begin{itemize}
  \item Löpande ekonomisk rådgivning
  \item Uppföljning av ekonomiska nyckeltal
  \item Stöd vid kontakt med myndigheter
\end{itemize}

\section*{3. Klientens skyldigheter}

Klienten förbinder sig att:

\begin{itemize}
  \item Tillhandahålla fullständiga och korrekta underlag i god tid
  \item Arkivera bokföringsmaterial i minst sju (7) år enligt bokföringslagen
  \item Informera Byrån omgående vid förändringar i verksamheten
  \item Samarbeta vid frågor rörande kundkännedom och verksamhetens art
  \item Säkerställa att fakturor och verifikationer uppfyller Skatteverkets krav
  \item Betala överenskommet arvode i tid enligt punkt 4
\end{itemize}

Vid bristande efterlevnad av ovanstående skyldigheter förbehåller sig Byrån rätten att säga upp avtalet med omedelbar verkan.

\section*{4. Ersättning}

\subsection*{4.1 Månadspris}
Klienten erlägger en månatlig avgift om:

\begin{center}
  \Large \textbf{4\,500 SEK per månad (exklusive moms)}
\end{center}

Denna avgift täcker de tjänster som anges i punkt 2.1--2.4 ovan.

\subsection*{4.2 Betalningsvillkor}
\begin{itemize}
  \item Fakturering sker månadsvis i förskott
  \item Betalningsvillkor: 10 dagar netto
  \item Vid försenad betalning debiteras dröjsmålsränta enligt räntelagen
\end{itemize}

\subsection*{4.3 Tilläggstjänster}
Tjänster utöver vad som anges i punkt 2 debiteras enligt överenskommelse eller enligt Byråns gällande timprislista (1\,200 SEK/timme exkl. moms).

\section*{5. Sekretess och dataskydd}

Byrån förbinder sig att behandla all information om Klientens verksamhet konfidentiellt och i enlighet med gällande dataskyddsförordning (GDPR). Information lämnas endast ut till myndigheter när så krävs enligt lag.

Klienten samtycker till att Byrån lagrar och behandlar företagsdata i digitala system (t.ex. Fortnox) för att kunna utföra uppdraget.

\section*{6. Ansvar och begränsningar}

Byrån ansvarar för att utföra tjänsterna med professionell omsorg och i enlighet med god redovisningssed. Byråns ansvar är begränsat till direkt skada som orsakats av vårdslöshet och uppgår maximalt till tolv (12) månadspriser enligt punkt 4.1.

Byrån ansvarar inte för:
\begin{itemize}
  \item Felaktigheter i underlag som tillhandahållits av Klienten
  \item Förluster till följd av Klientens egna beslut
  \item Skatter eller avgifter som inte betalats i tid på grund av Klientens försening
\end{itemize}

\section*{7. Kundkännedom (KYC)}

I enlighet med penningtvättslagen (2017:630) har Byrån genomfört kundkännedomskontroll av Klienten. Byrån förbehåller sig rätten att begära ytterligare information vid behov samt att avsluta samarbetet om Klienten inte uppfyller lagkraven.

\section*{8. Uppsägning}

Avtalet kan sägas upp av endera part med tre (3) månaders uppsägningstid. Uppsägning ska ske skriftligen.

Vid avtalsbrott eller väsentlig försummelse från Klientens sida kan Byrån säga upp avtalet med omedelbar verkan.

\section*{9. Tvist}

Tvist i anledning av detta avtal ska i första hand lösas genom förhandling mellan parterna. Om överenskommelse inte kan nås ska tvisten avgöras enligt svensk lag vid svensk domstol.
