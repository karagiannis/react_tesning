# Fortnox Supportärende - Mall för utvecklarportal-licens

## 📝 **STEG-FÖR-STEG:**

### 1. Logga in på Fortnox
- Gå till https://www.fortnox.se
- Logga in med ditt gamla konto (enskild firma)
- Även om firman är nedlagd finns kontot kvar

### 2. Hitta support-funktionen
**Alternativ A:** Via menyn
- Klicka på "?" eller "Hjälp" (oftast uppe till höger)
- Välj "Kontakta support" eller "Skapa ärende"

**Alternativ B:** Direkt länk
- https://support.fortnox.se (kan kräva inloggning)

### 3. Skapa supportärende

**Ämne/Rubrik:**
```
Ansökan om utvecklarportal-licens
```

**Meddelande (KOPIERA DENNA TEXT):**
```
Hej,

Jag vill ansöka om licens till Fortnox utvecklarportal för att utveckla integrationer.

Uppgifter:
- Namn: Lasse Karagiannis
- E-post: [din e-postadress som du vill använda för utveckling]
- Roll: Utvecklare/Systemadministratör

Bakgrund:
Jag utvecklar en onboarding-applikation för redovisningsbyråer som ska integrera med Fortnox API. Appen hjälper byråer att följa penningtvättslagens krav vid kundintroduktion.

Jag behöver:
1. Licens till utvecklarportalen
2. Möjlighet att skapa sandbox-miljöer för test
3. Tillgång till API-dokumentation och OAuth-konfiguration

Projektet är i utvecklingsfas och jag behöver sandbox-access för att testa integration innan eventuell framtida publicering.

Tack på förhand!

Vänliga hälsningar,
Lasse Karagiannis
```

---

## ⚠️ **VIKTIGT att veta:**

### Om ditt gamla Fortnox-konto:
✅ **Kontot finns kvar** även om firman är nedlagd
✅ **Du kan få utvecklarportal-licens** kopplad till detta konto
✅ **Sandbox-miljöer är separata** från ditt gamla företag

### Vad händer efter supportärende:
1. Fortnox support svarar (1-3 arbetsdagar vanligtvis)
2. De lägger till utvecklarportal-licens på ditt konto
3. Du får notification via mail/Fortnox
4. Du kan då logga in på https://www.fortnox.se/developer
5. Skapa sandbox-miljöer (upp till 30 stycken!)

### Om de frågar om företagsinfo:
```
Företagsnamn: [Ditt gamla företagsnamn eller "Privat utveckling"]
Org.nr: [Om du har - annars skriv "Hobbyverksamhet/Privat"]
Syfte: "Utveckling av integration för framtida LIA-placering"
```

## 🤔 **VILKET ALTERNATIV SKA DU VÄLJA?**

### **Alternativ 1: Ditt gamla konto**
✅ Snabbt - du gör det själv nu
✅ Fungerar för sandbox-utveckling
❌ Svårare att få live-nycklar senare (inget aktivt företag)
❌ När Fredrik ska använda live-appen måste han ändå göra OAuth via sitt företag

### **Alternativ 2: Fredriks företag** (REKOMMENDERAT)
✅ Live-nycklar blir enkelt senare
✅ Professionellt - kopplat till aktivt företag
✅ Fredrik kan testa direkt när det fungerar
❌ Kräver att Fredrik gör supportärendet
❌ Du måste vänta på att Fredrik har tid

**GÖR BÅDA!** 🎯

- Fredrik testar live på sitt företag

- Perfect multi-tenant architecture! 🎉
