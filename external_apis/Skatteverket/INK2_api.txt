Inkomstdeklaration 2 – hämta 1.0

API:et riktar sig till programvaruföretag som tar fram tjänster för de som hämtar Inkomstdeklaration 2. API:et möjliggör att hämta och visa upp Skatteverkets förifyllda deklarationsuppgifter i PDF- eller SRU-format direkt i programvaran.

Översikt

API:et Inkomstdeklaration 2 hämta - riktar sig till dig som skapar programvara för företag som hämtar Inkomstdeklaration 2. API:et gör det möjligt att skapa funktionalitet för att hämta och visa upp Skatteverkets förifyllda deklarationsuppgifter i PDF- eller SRU-format direkt i programvaran. Du kan också hämta status för deklarationer. Här får du översiktlig information om API:ets operationer, målgrupp och teknik.
Fördelar med att använda API:et

API:et Inkomstdeklaration 2 - Hämta via API låter dig som programföretag hämta de uppgifter som Skatteverket redan förifyllt på inkomstdeklarationen. Du får därmed in uppgifterna direkt i programmet och underlättar för kunden genom att de uppgifter som Skatteverket redan har förifyllt finns tillgängliga i programmet. API:et ger dig även enkelt tillgång att se status för deklarationer, vilket gör att du enkelt kan se t ex om deklarationen skrivits under och tagits emot av Skatteverket.

Med hjälp av API:et kan du

    minska risken för manuella fel
    få tillgång till förifyllda deklarationsuppgifter direkt i programvaran
    se om deklarationen signerats

Välj en av guiderna för att komma igång med API:et:
Kom igång med komplett testtjänst
Kom igång med driftsatt tjänst

Skatteverket tillhandahåller även API:et Inkomstdeklaration 2 - inlämning in via API. För att få ut störst nytta av det här API:et rekommenderas att du även använder dig av Inkomstdeklaration 2 inlämning via API.
Operationer

I API:et finns två operationer:

    Hämta förifyllda uppgifter
    Hämta status

Målgrupp

API:et riktar sig till dig som arbetar med utveckling av programvaror för deklarationsinlämning, antingen för bolag som lämnar in sin egna deklaration eller redovisningsbyråer och deklarationsombud.
Avgränsningar

    Tjänsten gäller enbart Inkomstdeklaration 2 och inga andra deklarationskategorier.
    Status garanteras enbart för senaste aktuella Inkomstdeklaration 2

Teknik

API:et finns tillgängligt som driftsatt tjänst och komplett testtjänst. Tjänsten kräver behörig företrädare exempelvis VD eller ombudsbehörighet, dvs en ombudsroll som ger tillgång till denna tjänst. Anrop mot tjänsten sker med en krypterad anslutning och auktiorisation sker med OAuth2.

Med API:et kan du hämta förifyllda deklarationsuppgifter som PDF (med SRU), PDF (utan SRU) eller som SRU-fil samt hämta status för inlämnade deklarationer. Ta hjälp av kodexemplen för att enklare förstå hur du ska använda operationerna.
