

Inkomstdeklaration 2-4 1.0

API:et kan användas för företag som lämnar Inkomstdeklaration 2, 3 och 4. Med API Inkomstdeklaration 2-4 kan du bland annat hämta och visa upp förifyllda deklarationsuppgifter direkt i programvaran.

Översikt

API:et Inkomstdeklaration 2-4 kan användas av dig som utvecklar tjänster där slutanvändaren är företag som lämnar Inkomstdeklaration 2, 3 eller 4. Med API:et går det att hämta förifylld inkomstdeklaration, skicka in samt se status för deklarationer. För att signera deklarationen måste behörig företrädare logga in på Skatteverkets Mina sidor.

Här får du översiktlig information om API:ets operationer, målgrupp och teknik.
Fördelar med API:et

Med det här API:et kan programvaruföretag underlätta för företag, redovisningsbyråer och deklarationsombud som hanterar Inkomstdeklaration 2, 3 och 4. API:et ger möjlighet till en helt digital hantering av hela inkomstdeklarationen i kundens egen miljö på ett enkelt och säkert sätt.

API:et låter dig som programvaruutvecklare hämta de uppgifter som Skatteverket redan förifyllt på inkomstdeklarationen. Du kan även hämta status för deklarationer. Status kan hämtas med information om deklarationen har skickats ut, om den skrivits under och tagits emot av Skatteverket samt om slutlig skatt har fastställts. Uppgifterna kan sedan visas i kundens programvara.

API:et gör det också möjligt att lämna in deklarationen direkt från programvaran. Behörig företrädare kan sedan logga in på Mina sidor och signera deklarationen.
Med en digital hantering av hela deklarationsprocessen direkt i kundens miljö minskas också risken för manuella fel.

På sidan komplett testtjänst kan du läsa mer om hur du gör för att använda API:et.

Kom igång med komplett testtjänst
Operationer

API:et har tre operationer:

    Hämta förifylld deklaration i PDF- eller SRU-format. Uppgifter som är förifyllda är underlag för fastighetsavgift och fastighetsskatt.
    Hämta status för deklaration. Status som kan hämtas är:
        Deklaration utskickad
        Deklaration inlämnad
        Slutlig skatt fastställd
    Lämna deklaration INK2, INK3 och INK4 i XBRL-format. Med operationen kan du även bifoga:
        Bilagorna N3B, N4, N7, N8 och N9
        Textfältet Övriga upplysningar

Behörigheter för operationerna:

    För att hämta förifylld deklaration eller deklarationsstatus krävs behörighet, det kan vara i form av ensam firmatecknare, VD, deklarationsombud eller läsombud.
    För att lämna deklarationen krävs ingen behörighet. Den som skriver under deklarationen på Mina sidor måste däremot vara behörig företrädare.
    När Inkomstdeklaration 3 innehåller särskilda uppgifter kan bara en ensam firmatecknare skriva under deklarationen – och inte ett deklarationsombud.

Inkomstdeklaration 2-4 1.0

API:et kan användas för företag som lämnar Inkomstdeklaration 2, 3 och 4. Med API Inkomstdeklaration 2-4 kan du bland annat hämta och visa upp förifyllda deklarationsuppgifter direkt i programvaran.

Exempel

Med API:et kan du hämta förifyllda deklarationsuppgifter, status för deklarationer och lämna in inkomstdeklarationer. Ta hjälp av våra testfall för att enklare förstå hur du ska använda operationerna.
Mappstruktur för operation Lämna inkomstdeklaration

Vi rekommenderar att du har en särskild struktur för de filer som du lämnar med operationen. Den översta nivån i mappstrukturen måste vara zippad.

Fem steg till en korrekt mappstruktur:
1. Skapa en mapp med namnet ”reports”. Mappens namn "reports" behöver skrivas med gemener (små bokstäver).
2. Spara samtliga filer som du tänkt skicka in i ”reports”-mappen. Det betyder att både filen för inkomstdeklaration samt alla bilagor måste sparas i mappen.
3. Spara alla xbrl-instansfiler med filändelsen .xbrl
4. Spara mappen "reports" i en huvudmapp med valfritt namn.
5. Komprimera huvudmappen till en zip-fil. Se till att den är base-64-kodad.

Exempel på en mappstruktur:
Huvudmapp: huvudmapp_reports.zip (den zippade mappen)
Mapp: reports (mappen där dina filer ska ligga)
Exempel: huvudmapp_reports.zip > reports > ink2.xbrl, n3b.xbrl, n4.xbrl, n7.xbrl, n8.xbrl
